# Random Task Generator - Генератор случайных задач

**Автор:** Бурковская Полина

## Описание

Десктопное приложение для генерации случайных задач из предопределённого списка. Позволяет отслеживать историю сгенерированных задач, фильтровать их по категориям, а также добавлять новые задачи в список.

## Функционал

- Генерация случайной задачи из списка (с кнопкой "Сгенерировать задачу")
- Отображение текущей задачи крупным шрифтом
- История всех сгенерированных задач с временем генерации
- Фильтрация истории по категориям (учёба, спорт, работа)
- Добавление новых задач с указанием категории
- Автоматическое сохранение списка задач и истории в JSON-файлы
- Валидация ввода (проверка на пустую строку при добавлении задач)
- Очистка истории с подтверждением

## Установка и запуск

### Требования
- Python 3.7 или выше
- Tkinter (встроен в стандартную установку Python)

### Запуск

1. Скачайте или склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш_логин/random-task-generator.git
   cd random-task-generator
Запустите приложение:

bash
python main.py
или

bash
python3 main.py
Примеры использования
Генерация случайной задачи
Запустите приложение

Нажмите кнопку "Сгенерировать задачу"

В верхней части окна появится случайная задача

Задача автоматически добавляется в историю

Добавление новой задачи
В поле "Название задачи" введите, например, "Выучить новый язык"

Выберите категорию (учёба, спорт, работа)

Нажмите "Добавить задачу"

Новая задача появится в общем списке для генерации

Фильтрация истории
В блоке "Фильтрация истории" выберите нужную категорию

Нажмите "Применить фильтр"

В таблице истории останутся только задачи выбранной категории

Очистка истории
Нажмите кнопку "Очистить историю"

Подтвердите действие

Вся история генераций будет удалена
